# Relay API contract (draft)

This is the shape of every API response, so the frontend can be built against mocks while the engine is finished.
Fields marked **(M1)** are live now and appear in `frontend/src/mocks/state.json` (generated by
`python scripts/make_mocks.py` from the real engine at 6:20 PM ET). Fields marked **(M2)** or **(M3)** are the planned
shape and may gain fields, but existing fields will not be renamed without updating this file.

All times are ISO 8601 with an offset, in Eastern time. Display strings such as `now_label` are already formatted.

## GET /api/state

```jsonc
{
  "now": "2026-03-17T18:20:00-04:00",          // (M1) the engine clock, not the computer clock
  "now_label": "6:20 PM ET",                    // (M1)
  "scenario_date": "2026-03-17",                // (M1)
  "physicians": [Physician],                    // (M1)
  "consults": [Consult],                        // (M1) open consults only
  "data_health": DataHealth,                    // (M1)
  "hospitals": [Hospital],                      // (M2)
  "issues": [IssueGroup],                       // (M2) ranked, most urgent first
  "gaps": [Gap],                                // (M2) projected coverage gaps
  "projection": Projection,                     // (M2)
  "offers": [Offer],                            // (M3)
  "summary": {"critical": 4, "warning": 6, "pending_approvals": 1}   // (M2)
}
```

  "hospital_ids": ["SYN-010"],

## Other endpoints (M2 and M3)

| Method and path | Purpose |
|---|---|
| `GET /api/issues/{id}` | Issue detail: recommendation, ladder results, alternatives with "why not", 90-minute strip |
| `GET /api/eligibility?gap_id=...` | Every off-shift physician with each rule passed or failed |
| `POST /api/offers/propose` | Coordinator proposes a ranked offer plan |
| `POST /api/offers/{id}/approve`, `/reject` | Clinical lead decision |
| `POST /api/offers/{id}/accept`, `/decline`, `/online` | Phone replies |
| `GET /api/offers/{id}` | Phone view (no patient details) |
| `POST /api/actions/reassign`, `/escalate`, `/undo` | Coordinator actions |
| `POST /api/events/upload` | Append a CSV of new events (no restart); returns the load report |
| `POST /api/events` | Append one event |
| `POST /api/reset` | Back to the kit data at 6:20 PM |
| `POST /api/clock` | `{"action": "set" | "advance" | "play" | "pause", "minutes": 5, "to": "..."}` |
| `GET /api/simulate/flood-guard?gap_id=...` | Routing simulation with and without the flood guard |
| `GET /api/scoreboard`, `/api/insights/credentialing`, `/api/handoffs`, `/api/audit` | Standouts |
| `GET /api/health` | Service health |
